# Aquagrip
This application serves as the control and monitoring of the Aquagrip Program installed in the ESP32. This app uses Firebase Realtime Database to obtain data from the current state of the ESP32 microcontroller. This app also send commands to the ESP32 microcontroller using the database. Any changes to the database is directly reflected to the app.

Note: Firebase Realtime Database credentials in the google-services.json is intentionally removed. This project is for showcasing only. ESP32 Program is also not included in this project.
